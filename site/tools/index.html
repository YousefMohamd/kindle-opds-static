📚 من المكتبة الشاملة إلى EPUB 🌐 المتصفح — كمبيوتر أو هاتف

حمّل أي كتاب من المكتبة الشاملة (تراث) بصيغة EPUB جاهزة للكيندل، بلا تثبيت.

الخطوات:

  1. افتح مكتبة تراث — app.turath.io في المتصفح.
  2. ابحث عن الكتاب وافتحه.
  3. حمّل نسخة EPUB، ثم أرسلها إلى كيندلك (Send-to-Kindle أو USB).

تنبيه: إضافة المتصفح القديمة shamela-epub-exporter توقّف صيانتها وأرشفها صاحبها نفسه، وهو يوجّه إلى تراث بدلاً منها — لذلك نرشّح تراث، لا الإضافة.

الإضافة الأرشيفية مرخّصة GPL-3.0 — للاطّلاع فقط، لا تثبّتها.

🖼️ من قصص مصوّرة (CBZ / CBR / PDF) إلى EPUB 💻 الكمبيوتر

حوّل مجلد صور أو ملف CBZ/CBR/PDF إلى EPUB مضبوط على مقاس كيندلك أو كوبو — مع تقسيم تلقائي للملفات الكبيرة.

الخطوات:

  1. ثبّت Go — حمّله من go.dev/dl — ثم ثبّت الأداة: go install github.com/celogeek/go-comic-converter/v3
  2. حوّل ملفك (مثال: بروفايل SR لكيندل عادي): go-comic-converter -profile SR -input ~/Download/MyComic.cbz
  3. ستجد الناتج MyComic.epub بجانب الملف الأصلي — أرسله إلى كيندلك (حدّ الإيميل 50MB، والموقع 200MB؛ الأداة تقسّم الملف تلقائياً كل 200MB).

go-comic-converter على GitHub — MIT، الإصدار 3.0.0، نشطة.

🔍 OCR — اجعل الكتب الممسوحة قابلة للبحث 📖 KOReader على القارئ 💻 الكمبيوتر

الكتب الممسوحة (صور بلا نص) لا يمكن البحث فيها. الحلّ أحد طريقين — اختر الطريق الذي يناسبك:

أ) داخل KOReader (على القارئ نفسه):

  1. حمّل ملفّي اللغة ara.traineddata و eng.traineddata (بيانات Tesseract 5، من مستودع tessdata_fast الرسمي).
  2. انسخهما بالـ USB إلى مجلد koreader/data/tessdata على القارئ.
  3. في ملف koreader/defaults.custom.lua أضف السطر: DKOPTREADER_CONFIG_DOC_LANGS_CODE = {"ara", "eng"} — إن لم يكن الملف موجوداً، أنشئ ملفاً جديداً بهذا الاسم.
  4. افتح الـ PDF الممسوح في KOReader — البحث في الصفحة والبحث في القاموس سيعملان الآن عبر OCR.

ب) على الكمبيوتر قبل النقل (أفضل للكتب الكبيرة):

  1. ثبّت OCRmyPDF: sudo apt install ocrmypdf tesseract-ocr-ara tesseract-ocr-eng (أوبنتو/ديبيان) أو brew install ocrmypdf tesseract-lang (ماك).
  2. شغّل: ocrmypdf -l ara+eng input.pdf output.pdf
  3. انقل output.pdf إلى قارئك — أصبح فيه طبقة نص قابلة للبحث والنسخ.

توثيق KOReader للـ OCR · توثيق OCRmyPDF — OCRmyPDF مرخّص MPL-2.0، وبيانات Tesseract مجانية مفتوحة.
