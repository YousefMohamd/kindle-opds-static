# Mandatory channel — content plan (PLAN ONLY — no channel created)

Status: **plan only, prepared 2026-11-14. No channel has been created**
(creating it needs the user: name, handle, and the mandatory-join setup).

## What the channel is

- The official RliBook announcements channel. Users must join it first
  (mandatory channel / forced subscription) before using the bot's services.
- Language: Arabic (Egyptian dialect, same voice as the group message),
  with English where a feature name needs it.
- Tone: short, honest, useful. One post = one thing. No hype, no spam.
- Brand: RliBook — Reply. Read. Fly. / رد. اقرأ. حلّق.
- Every post ends with the two links: https://rlibook.tech ·
  https://t.me/RliBook_bot

## What goes in it

1. **New features** of the website and the bot (each release, in plain
   words: what changed, what button to press, what it does for you).
2. **Global reading events, especially in the Arab world** — e.g. Cairo
   International Book Fair, World Book Day / World Reading Day,
   Arab Reading Challenge, Sharjah / Riyadh / Abu Dhabi book fairs,
   Ramadan reading lists, back-to-school reading picks.
3. **Library marketing inside the channel** — how the libraries in the
   catalog are presented and promoted (see the open question below).
